# Evidencia 2
Este proyecto se desarrolló en C++ y utiliza Double Linked List, Queue y Stack para trabajar con archivos de logs, permitiendo ordenar registros con Merge Sort, buscar por fecha y mostrar estadísticas.

## Compilación y ejecución
Para ejecutar el programa principal:
```bash
g++ -std=c++20 main.cpp -o main
./main
```

Para ejecutar las pruebas de las estructuras:
```bash
g++ -std=c++20 pruebas.cpp -o pruebas
./pruebas
```

Los archivos `log607-1.txt` y `log607-2.txt` deben estar en la misma carpeta desde donde se ejecuta el programa.

## Formato de fecha
El programa solicita mes, día y año por separado. El mes se escribe con las primeras tres letras en inglés.
Ejemplo: `Sep 7 2026`
También se validan los días de cada mes y los años bisiestos.
